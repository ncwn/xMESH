# Hardware Abstraction Layer
Abstract the Canarin ports multiplexing system and allows drivers to operate the peripherials by managing the mux switching.

## Ports
Ports are indexed from 0 to CAN5_PORT_COUNT but they have different properties

We can identify
1. NET ports
NETPORT_0 - NETPORT_COUNT
Serial interface
Not multiplexed, every port has a dedicated serial
Has an Interrupt dedicated
NETPORT_0 is reserved for the internal WiFi

2. AD ports
ADPORT_0 - ADPORT_COUNT
Can be Analog  Input or Digital I/O

3. U ports
UPORT_0 - UPORT_COUNT
Serial Interface
Multiplexed


HAL module opens the basic HW access functions:
Port Enable/Disable (by driving the EN line)
Serial Read/Write (for NET and U ports)
Digital Read/Set (for AD ports)
Analog Read (for AD ports)
I2C bus Read/Write


HAL registers to interrupts and publishes HAL Events to the system queue.

*Events:*
CAN5_HAL_EVT_WAKE: is generated when an interrupt on the WAKE pin is generated by a Negative Egde
